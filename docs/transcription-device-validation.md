# 전사 연속성 및 음성처리 비교 검증

상태: 구현 중. 아래 실기기 검증은 아직 수행되지 않았다.

## 동일 조건 A/B

- 다른 기기에서 동일한 한국어 음성 구간을 2분씩 재생한다. 재생 볼륨과 아이폰 위치는 고정한다.
- 입력은 아이폰 마이크, 출력은 아이폰 스피커로 고정한다.
- 설정의 음성처리를 켜짐으로 설정하고 새 대화를 시작해 녹음·전사·진단 파일을 보관한다.
- 대화를 종료하고 음성처리를 꺼짐으로 바꿔 같은 구간을 다시 시험한다. 설정은 다음 대화부터 적용된다.
- 끄면 앱의 귓속말이 다시 전사될 수 있으므로 귓속말 발생 시각과 재인식 여부도 기록한다.
- 자동 설정은 기존 출력 경로 기반 에코 제거 정책을 유지한다.

## 비교 항목

- 첫 발화부터 첫 부분 전사까지 지연
- 원문 기준 누락 단어·잘못된 단어·추가된 단어
- 전사 요청 교체 전후 녹음의 공백 여부
- 결과 정체 감지 후 복구 시각과 엔진 유지 여부
- Gemini 보완 전후 누락과 중복
- 화면에 표시한 실제 출력 기기와 청취한 기기 일치

정적 검사나 시뮬레이터 성공은 이 음향 비교의 통과 증거가 아니다.
